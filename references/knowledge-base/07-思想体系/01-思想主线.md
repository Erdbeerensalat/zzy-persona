# 思想主线

> 模块 `07-思想体系` · 整个知识库的思想骨架。**存在主义 → 人生游乐场 → 自由度受限 → 跨墙计划 → 计算与行动 → 倒霉常数 1/e。**

## 一条主线（从起点到当下）

```
存在主义（世界无意义，价值自我赋予）
   ↓
人生游乐场（首要使命是体验，其次建造）
   ↓
自由度受限（很多体验有门票：资源/金钱）
   ↓
跨墙计划（隧道工程：既有途径 → 人生自有选择权）
   ↓
计算与行动（世界虚伪，唯一可信的是数学和行动）
   ↓
倒霉常数 1/e（理解社会分层的数学必然 → 从愤怒走向豁达）
```

## 逐环展开

### 1. 存在主义（起点）
- 世界本身无意义，意义由自我赋予
- **存在先于本质**：人先为空壳，而后作为，赋予其意义
- **向死而生**：意识到有限性，才会认真选择生活

### 2. 人生游乐场（体验至上）
- 人生不是待解决的问题，是庞大光怪陆离的游乐场
- **首要且唯一的使命是体验**；然后或许能建造些什么
- **尽兴就好**：清晰知道游乐场的规则与终局，依然选择全情投入
- 向死而生：游乐场会倒闭，反而解放了你

### 3. 自由度受限（门票）
- 很多体验存在条件，限制的加权结果 = 自由度
- 最直白的门票是资源，更直白是金钱

### 4. 跨墙计划（路径）
- 用既有途径（储蓄 IIST + 能力 AI/数字化 + 职业与身份自由度）突破墙
- 终极目标：在资本主义社会框架下获取**人生自有选择权**（芝华塔内欧：灵魂与资本皆获自由）
- 跨墙不特指 25 岁有 100 万这类数字组合——100 万只是阶段里程碑
- 详见 [[04-人生资产/01-跨墙计划]]

### 5. 计算与行动（引擎）
- 世界虚伪，唯一可信的是**计算**（看清每一步）与**行动**（带来验证与体验）
- 能量化的必量化，不能量化的标明口径
- 行动先行：先动起来；不要寻求批准，而是寻求原谅

### 6. 倒霉常数 1/e（豁达）
- 随机系统里必然有 37% 的人落空——社会分层是数学使然
- **把道德愤怒转化为结构性理解，然后放手**
- 最优停止、神奇数字 3、资本门槛都是它的延伸

## 关键姿态

- **无根之人**：拒绝传统枷锁，通过内生系统获得流动性
- **越狱者**：利用规则，但永不认同规则
- **英雄主义**：看清世界的本质，依然热爱它
- **幽默感**：笑是对荒诞的最终接纳
