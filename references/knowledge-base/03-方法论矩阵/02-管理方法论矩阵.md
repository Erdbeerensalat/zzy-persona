# 管理方法论矩阵（五级）

> 模块 `03-方法论矩阵` · 从战略到经营的全层级管理工具箱。工作时按场景调用，不必全背。

## 战略层

- **PD**：Perfect Delivery（完美交付）
- **CVD**：Cost/Value/Delivery（成本/价值/交付）
- **VOB / VOC**：Voice of Business / Voice of Customer（业务之声/客户之声）
- **极致成本**：结构性降本，不只是砍价（参考 Y32 项目 27.8% 综合降本）
- **MOB**：Monthly Operating Business（月度经营分析）

## 运营层

- **DM**：Daily Management（日常管理/早会闭环）
- **BBS**：Bull-Business System（公牛经营系统：5S / DM / PSP / TPI）
- **SMED**：快速换模（Single Minute Exchange of Die）
- **TPM**：全员生产维护
- **短周期管理**：10min / 1h 分级响应
- **早会闭环**：每日台账逐项闭环

## 项目层

- **PDCA**：Plan-Do-Check-Act
- **TPGM**：目标-过程-管理
- **SMART**：具体/可测/可达/相关/有时限
- **WBS**：工作分解结构
- **Stage-Gate**：阶段门评审
- **IPD**：集成产品开发

## 管理层（向上管理）

- **向上管理七步法**：理解上级目标 → 对齐节奏 → 主动汇报 → 管理预期 → 提供方案 → 借力资源 → 建立信任
- **AIM 表达**：Action（动作）- Impact（影响）- Message（要点）
- **PREP 汇报**：Point → Reason → Example → Point

## 经营层

- **净利润流程点检**：从订单到回款全流程找利润泄漏点
- **人效指标**：人均产值、人均毛利
- **年化效益核算**：异常工时降 38.9% → 年化 220 万（口径：月度 × 12）
