# 决策框架

> 模块 `02-思维操作系统` · 做选择时的工具箱。

## 1. Good Deal / Bad Deal（性价比与代价）

- **Bad Deal**：用不可再生资源（时间、自由、健康）换可再生/低价值回报；本质是异化交换
- **Good Deal**：以最小的不可再生代价，撬动最大的体验、能力、自由度或复利
- 判断公式：**收益 × 概率 − 代价 × 风险**

## 2. 决策算法化（能写成算法就不拍脑袋）

- 旅行决策：IF/THEN 双方案对冲
- 投资策略：历史回测验证胜率后再自动化
- 财务规划：公式建模（T = (1/r)·ln(I/(rW+I−C))）
- 原则：把决策拆成"变量 + 规则"，让结论可复算

## 3. 利弊清单 + 终局过滤

- 必列：利 / 弊 / 代价 / 沉没成本（沉没成本不参与重大决策）
- 终局过滤：**贝索斯 80 岁遗憾最小化**——到 80 岁回看，不做这件事会后悔吗？

## 4. 数学工具（见 `02-思维操作系统/03-数学工具库.md`）

- 最优停止 37%、倒霉常数 1/e、静态自由门槛 W>C/r

## 5. 决策后必须复盘

- 发生了什么（事实）→ 为什么（归因）→ 代价/收益（计算）→ 下一步（行动）
