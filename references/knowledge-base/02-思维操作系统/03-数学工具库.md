# 数学工具库

> 模块 `02-思维操作系统` · 用数学把模糊选择变成可复算的决策。**世界虚伪，唯一可信的是计算与行动。**

## 1. 倒霉常数（1/e ≈ 36.8%）

- **定义**：lim_{n→∞}(1−1/n)^n = 1/e ≈ 36.79%
- **直觉**：n 个人随机分 n 块蛋糕，基数足够大时，必有约 37% 的人什么也得不到。这是**纯粹随机系统里"一无所有"群体的自然比例**。
- **倒霉函数** y=(1−1/x)^x：x=3.13 时 y≈0.3——**只要 3 人及以上，就有 30%+ 概率有人落空**。
- **推论**：有限资源 × 随机博弈 ⇒ 社会分层必然。落空、积累、平衡循环出现。
- **用途**：理解"凭什么是我"——把道德愤怒转化为结构性理解，然后放手（豁达来自数学）。
- **呼应**：中国收入分布 20%+20%=40% 与 1/e≈37% 的巧合。

## 2. 最优停止理论（37% 法则）

- **问题**：面试 N 位候选人，必须立即决定，如何最大化选到最佳者的概率？
- **策略**：放弃前 37% 作观察学习期，之后遇到比之前都好的人立刻选。
- **落地**：先投 37% 成本建立模型，再进入决策阶段。必然有一部分人沦为学习成本——接受它。

## 3. 本福特定律 & 神奇数字 3

- **本福特定律**：实际数据以 1 开头的概率约 30%，数据在对数尺度上均匀分布。
- **储蓄本质**：固定复利使金额对数随时间线性增长——与"对数均匀"共享同一数学结构。
- **神奇数字 3**：设利率恒定，从 a 增长到 3.1623a 与从 3.1623a 到 10a 耗时相等。
  - **1→3.1623 的难度 = 3.1623→10 的难度**。
  - 因此 **31.623 万是明显的分水岭**——跨越它之后复利开始加速（IIST 第二阶段目标即 31.623 万）。

## 4. 静态自由门槛（W > C / r）

- **公式**：W_free > C / r
  - W = 初始资本，C = 年刚性支出，r = 资本回报率
- **含义**：资本产生的被动收入（W×r）大于年支出时，资本才能"自己养活自己"，摆脱对劳动收入的依赖。
- **示例**：C = 3.6万/年，r = 3% ⇒ 需 ≥120 万存款。
- **来源**：富勒"不工作能活几天"追问 → 清崎被动收入框架 → Trinity Study 4% 法则。

## 5. 动态自由年限（T 公式）

- **公式**：T = (1/r)·ln( I / (rW₀ + (I−C)) )
  - I = 年收入，C = 年支出，S = I−C 年储蓄，r = 理财能力，W₀ = 初始资金
- **含义**：按当前条件，还需要多少年才能不工作。
- **三杠杆**：
  - **储蓄能力 S 决定你跑多快**（最可控、第一把钥匙）
  - **理财能力 r 决定你跑多远**（直接关联自由门槛）
  - **收入能力 I 决定你的上限**
- **示例**：C=7、S=7、r=3% ⇒ W_free=233万、T=20年；C=7、S=8、r=5% ⇒ W_free=120万、T=8年。

## 6. 决策算法化（能写成算法就不拍脑袋）

- **旅行候补**：IF/THEN 双方案对冲（A 候补 vs B 保底，设决策节点）
- **AI 策略**：先在历史战场回测胜率，胜率高才开发自动化
- **财务**：公式建模 + 让 deepseek 交叉验证（T=42.46 年的算例）
- **原则**：把决策拆成"变量 + 规则"，让结论可复算、可回测。

## 7. 终局过滤器

- **贝索斯 80 岁遗憾最小化**：想象 80 岁的自己回望，会不会因这次尝试而后悔？"哪怕失败我也不遗憾，可能因没尝试而悔恨。"
- **永恒轮回**：若此事要无限重复，你愿不愿意？→ 为每个行动赋予"无限重复"的权重。
- **沉没成本**：过去已下桌，决策只看未来——"如果今天才开始，你愿不愿意？"

## 8. 决策形态分层：帽子 vs 头发 vs 纹身

- **帽子**：即时性选择，不痛不痒（今天吃什么）
- **头发**：需适应，阶段影响（工作选择、阶段性投入）
- **纹身**：半终生决定，底层改变（婚姻、定居）——需要最重的斟酌
- **用法**：先给决策定性，再决定投入多少斟酌成本。

## 9. 常见认知陷阱清单

| 陷阱 | 本质 | 破解 |
|---|---|---|
| 双曲贴现 | 偏好眼前小利 | 用长期复利视角定价 |

| 目标替代 | KPI 达成≠目标达成 | 手段回归目的（"每天接客≠20年后赎身"） |
| 平均陷阱 | 变成身边人的平均值 | 主动筛选圈子 |
| 聚光灯效应 | 高估别人对自己的注意 | 他人没你想的那么关注你 |
| 廷波克预期 | 高预期导致强落差 | 不沉迷预期，接受事情可能失败 |
