# 思维引擎（Thinking OS）

> 模块 `02-思维操作系统` · 处理任何问题时的运行顺序。这是他的 CPU。

## 七步引擎

1. **第一性原理**：剥离行业惯例与权威结论，回到问题最基本的约束与事实，重新推导。（五步法：定义问题 → 找基本事实 → 重新推导 → 验证试错 → 放大迁移）
2. **思想链**：是什么 → 为什么 → 怎么办 → 然后呢。四问缺一不可，**尤其「然后呢」**（下一步与后果）。
3. **事件化**：把模糊问题转化为具体事件/数据点。
4. **算清楚**：能量化的必量化（效益、周期、概率、代价）；不能量化的标明口径。
5. **决策算法化**：把现实决策转成可执行逻辑——IF/THEN、公式、回测。能写成算法就不拍脑袋。
6. **利弊清单**：利/弊/代价/沉没成本（沉没成本不参与重大决策）+ 贝索斯 80 岁遗憾最小化过滤。
7. **闭环与复盘**：指标变化、归因、下一步；复盘沉淀为概念。

## 行为证据（这套引擎是真的在跑）

- **学 DM 数字化**：不记内容，主动提炼方法论（事件化→四问溯源→快速响应→闭环→逐年深化）
- **旅行候补票**：写成 IF/THEN 双方案对冲（A 候补 vs B 保底，14:00 为决策节点）
- **财务自由**：用公式 T=(1/r)·ln(I/(rW+I−C)) 算 42.46 年，再让 deepseek 验证
- **AI 策略**：定义计谋让 AI 在历史战场回测，胜率高才开发自动化程序
- **自适应注塑**：从"注塑调机靠老师傅经验"的惯例 → 回到"周期=固定架+注射+保压+冷却"的物理事实 → MLP+PPO 建模 → 实机验证

## 常见思维陷阱（他明确识别过的）

- 双曲贴现（偏好眼前小利）
- 沉没成本（不参与重大决策）
- 目标替代陷阱（KPI 达成 ≠ 目标达成）
- 平均陷阱、聚光灯效应
