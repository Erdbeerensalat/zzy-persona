# 风险盲区自检

> 模块 `08-决策档案` · 决策前/决策后自查。**检查自己有没有踩坑——这是最容易被忽视的一步。**

## 认知陷阱自查清单

| 陷阱 | 识别信号 | 自检问题 |
|---|---|---|
| 双曲贴现 | "先爽了再说""以后再说" | 我在为眼前小利牺牲长期复利吗？ |
| 沉没成本 | "都付出这么多了" | 如果今天才开始，我还愿意吗？ |
| 目标替代 | "KPI 达成了" | 我完成的是手段还是目的？最终自由被替代了吗？ |
| 平均陷阱 | "大家都这样" | 我是不是被身边人的平均值同化了？ |
| 聚光灯效应 | "别人都在看我" | 别人真的在意吗？还是我高估了？ |
| 完美主义 | "还不够好，再等等" | 完成是否比完美更重要？我是不是在用完美主义拖延？ |
| 廷波克预期 | "他/她应该……" | 我是不是对他人有过度预期？预期落空是否放大了痛苦？ |
| 中庸陷阱 | "不上不下也还行" | 我是不是仰望梦想又安于现状？ |
| 共识陷阱 | "大家都说好" | 大众共识是不是被资本引导的？真实价值被高估了吗？ |
| 煤气灯效应 | "我是不是太敏感了" | 我在被削弱自我认知吗？"凭什么拿掉？" |

## 行为盲区自查（基于人格评估）

- **过度自省** → 行动力被内耗吃掉（心流#必须冒险："一个人不该过分自省，这会使他变得软弱"）
- **完美主义预期** → 对人对己预期过高，落差放大（廷波克预期）
- **三线并行高压** → 工作筹码/自由度/创作三条线互相挤占，警惕"清醒的痛苦"复发
- **理性化的情感压抑** → 用框架分析一切，可能回避真实情绪（情感张力提醒：爱是输出，不是交易）
- **财务纪律 vs 体验的张力** → 双曲贴现的两头：过度省钱错过体验，或过度消费伤跨墙进度（用 Good Deal 定价）

## 每次决策后的三问

1. 我踩了哪个陷阱？（对照上表）
2. 哪个环节我没算清楚？（数据/概率/代价）
3. 如果重来一次，我会改变什么？
