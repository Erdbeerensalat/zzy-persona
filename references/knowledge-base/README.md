## 使用方式

- **导航**：从 `00-地图/知识库地图.md` 进入，按模块索引
- **找框架**：遇到决策/分析/评审 → 进 `02-思维操作系统/`
- **找方法论**：工作/数字化/AI 场景 → 进 `03-方法论矩阵/`
- **找资产**：跨墙/财务/职业成果 → 进 `04-人生资产/` 与 `05-职业与项目/`
- **找定位**：想搞清"我是谁、我在哪、往哪去" → 进 `01-我是谁/` 与 `07-思想体系/`
- **做决策**：重大决定 → 打开 `08-决策档案/` 的模板与复盘
- **AI 调用**：场景路由见父级 `SKILL.md` 的「知识库路由」一节
