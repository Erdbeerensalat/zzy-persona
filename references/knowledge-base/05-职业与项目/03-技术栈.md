# 技术栈

> 模块 `05-职业与项目` · 数字化/AI 转型的武器库。**弄斧要去班门，做 AI 要去专业公司——但自己得先有锤子。**

## AI / 机器学习

- **框架**：PyTorch
- **算法**：PPO（强化学习）、MLP、随机森林、Actor-Critic
- **环境**：Gym 自定义环境（自适应注塑仿真）
- **硬件**：RTX 3060 6GB、CUDA 12.8、Python 3.13

## 数据 / 后端

- **数据**：Pandas、HuggingFace Datasets
- **后端**：Flask、frp（内网穿透）
- **企业系统**：MES、SAP、COPT
- **供应商 API**：海天鸿讯 API

## 办公自动化

- Excel VBA 宏（报表自动化：2 小时→10 分钟）
- FineReport（数字项目管理平台报表）

## 方法论工具

- BBS（5S/DM/PSP/TPI）、SMED、TPM、PDCA、IPD、Stage-Gate
- 见 [[03-方法论矩阵/02-管理方法论矩阵]]

## 一句话技术观

- **行动为先**：不是先学好了再干，而是干起来再学习
- **第一性原理**：回到基本事实重新推导（注塑=物理过程，不靠老师傅玄学）
- **最小验证**：POC → 实机验证 → 放大迁移
