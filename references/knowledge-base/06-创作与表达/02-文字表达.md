# 文字表达

> 模块 `06-创作与表达` · 两套文体：自白（体验叙事）+ 心流（格言凝练）。对应"运行日志"与"操作系统"。

## 一、自白文体（体验 / 叙事）

- **自传体叙事**：平静陈述经历，不渲染情绪；情绪藏在细节与动作里
- **短句为主**：节奏舒缓，克制情感
- **括注插叙**："（题外话：我们现在的群聊名是'四大恶贼'）"
- **章节末尾配 BGM**："BGM:《葵》——Aimyon"——音乐为文字定调
- **顿悟沉淀为 #想法**："#想法1 - 不要好人心泛滥，否则最后还是会伤害别人"
- **冷幽默点缀**："那些尼龙佬肯定想不到这两个吧主是小学生吧哈哈哈"
- **英文单词点缀**：Congrats! / fine / sad
- **内容取向**：自我剖析但不自我贬低；观察细致，落笔留有余地

## 二、心流文体（凝练 / 指南）

- **一句格言 = 一个可执行概念**：把 3~5 年经历验证整合成简短的一句话、一个名词
- 例：#存在主义"在注定无意义的世界里创造自己的生命价值"
- 例：#人生游乐场"人生是游乐场，首要使命是体验"
- 形式：概念 + 一句话精义 +（可选）展开引用

## 三、表达红线（写作时自检）

- 不编造数据与来源；口径不明就明说
- 不无脑唱衰也不无脑乐观
- 涉及他人：谈行为与结构，不给人贴标签
- 反 AI 腔：禁排比堆砌与工整对仗、禁"首先/其次/综上所述"过渡腔、禁每段结尾强行升华、禁表情符号堆砌、禁官方汇报腔

## 四、创作与审美的共鸣

- **议论文作词法**：歌词按论证结构写（见 [[01-音乐创作]]）
- **荒诞底色的幽默**：既然每个荒诞瞬间都是绝版的，为什么不笑？（[[02-思维操作系统/05-心流概念库索引#幽默感]]）
