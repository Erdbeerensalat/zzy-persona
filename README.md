# zzy-persona · 周泽宇理性人格范式

一个可直接安装到 AI 助手的「人格技能」：把一套理性思维与表达方式沉淀为 AI 可执行的范式。加载后，AI 以周泽宇的视角处理任务——

> **先算清楚，再行动；用数据说话，用结构表达，用数学获得豁达。**

适用于 GitHub Copilot、Claude 等支持 Skill / 自定义指令的 AI 工具。

## 它解决什么问题

AI 的默认输出有一种「AI 腔」：首先 / 其次 / 综上所述、工整排比、结尾强行升华、句长均匀。本 Skill 用一个人的真实思维与语言习惯做约束，让 AI：

- **分析时先算清楚**：给口径、给公式、给 IF/THEN，而不是给形容词
- **表达时分场景**：聊天像聊天，方案像方案
- **输出前过自检**：按「AI 腔自检」红线清单过滤机器人味

## 核心能力

| 能力 | 说明 |
|---|---|
| 双通道表达 | 对话通道（闲聊 / 报数 = 短句连击、接话、梗点缀）与交付通道（方案 / 评审 / 复盘 = 结论先行、方法论为骨、直给不粉饰），先判断场景再选通道 |
| 思维操作系统 | 第一性原理 → 思想链（是什么 / 为什么 / 怎么办 / 然后呢）→ 事件化 → 算清楚 → 决策算法化 → 利弊清单 → 闭环复盘 |
| 决策工具库 | Good Deal / Bad Deal、静态自由门槛、最优停止 37%、双曲贴现识别、80 岁遗憾最小化模型——决策能写成算法就不拍脑袋 |
| AI 腔自检 | 输出前的反机器人腔红线清单 |
| 知识库路由 | 按场景取用知识库（决策 / 复盘 / 写作 / 数字化方法论 / 财务框架……），用哪个读哪个，不整库加载 |

## 安装

**GitHub Copilot（VS Code）**：克隆到 Copilot 技能目录即可：

```bash
git clone https://github.com/Erdbeerensalat/zzy-persona.git ~/.copilot/skills/zzy-persona
```

Windows 下对应路径为 `C:\Users\<用户名>\.copilot\skills\zzy-persona`。

**其他 AI 工具**：把本仓库放到该工具约定的 skills 目录下（目录名保持 `zzy-persona`）；或直接将 `SKILL.md` 内容并入系统提示词 / 自定义指令。

## 使用

加载后默认全时生效：

- 日常闲聊、简单问答 → 对话通道
- 方案、评审、复盘、写作 → 交付通道
- 深度分析 → 运行思维操作系统（思想链四问 + 利弊清单 + 闭环）
- 需要引用概念或方法时 → 按 `SKILL.md` 的路由表，只读所需的知识库文件，不整库加载

## 说明

- 本仓库是个人实践项目；知识库为**脱敏版**，私人明细与隐私不入库。
- 涉及重大人生 / 财务决策时，范式只提供分析框架与利弊推演，决定权归本人。
